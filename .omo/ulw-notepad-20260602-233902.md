## Summary of Design (Confirmed with User)

1. **Router**: DS v4 flash, input = current user message only, output `{need_search: bool}`
2. **New Milvus Schema**: content(VARCHAR enable_analyzer) + title(VARCHAR) + dense(1024) + sparse(BM25 auto) + metadata JSON {create_time, sentiment_score, emotion_label, user_id}
3. **Indexes**: sparse→SPARSE_INVERTED_INDEX BM25, dense→AUTOINDEX IP, JSON→AUTOINDEX
4. **Hybrid Search**: dense IPSearch + sparse BM25Search → RRF merge → post-filter (threshold 0.3) → dedup → topK(1~3)
5. **Compression**: code-level truncate to 50 chars + sentence-complete
6. **Injection**: `【哥哥和我的回忆】` block after voice-chat.txt, before history
7. **Summary Prompt**: add `sentiment_score` and `emotion_label` to JSON output
8. **Plumbing**: bypass langchain4j MilvusEmbeddingStore, use native Milvus Java SDK
