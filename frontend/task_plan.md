# 微信小程序 MVP 计划

## Goal
围绕“AI 女友互动 + 记忆沉淀 + 实时语音陪伴”设计微信小程序 MVP，并输出可执行的产品、接口、前端、记忆与排期文档。

## Scope
- 文本聊天
- AI 文字/TTS 回复
- 实时语音会话
- Live2D 展示（实时语音页）
- 回忆页
- 基础个人中心与偏好设置
- MVP 开发排期

## Non-goals
- 不设计 STT 输入链路
- 不扩展社区/社交功能
- 不做复杂会员体系
- 不做多角色与重剧情系统

## Scenarios
1. Happy path: 团队能从文档直接看出 MVP 包含哪些页面、模块、接口、数据与排期。
2. Edge: 即使砍掉 STT、会员、复杂游戏后，方案仍然形成完整闭环。
3. Regression: 新的小程序规划不与现有前端文档中“后端托管记忆”方向冲突。
